# 심박수·혈중산소 모듈 - GUI 사용자 가이드

## 📋 기능

다음은 그래픽 기반 심박수·혈중산소 모니터링 프로그램으로, 다음과 같은 기능을 제공합니다:

1. ✅ **시리얼 포트 선택** - 사용 가능한 시리얼 포트를 자동으로 스캔합니다
2. ✅ **보드레이트 선택** - 9600/19200/38400/57600/115200 지원
3. ✅ **연결/연결 해제** - 클릭 한 번으로 모듈 연결/연결 해제
4. ✅ **수집 시작/중지** - 센서 LED 점등/소등 제어
5. ✅ **모니터링 시작/중지** - 실시간 데이터 표시
6. ✅ **실시간 데이터 표시** - 혈중산소, 심박수, 온도
7. ✅ **영어 / 중국어 전환** - 언제든지 인터페이스 언어를 전환할 수 있으며, 기본값은 영어입니다

---

## 🔌 하드웨어 연결

| 심박수·혈중산소 모듈 | USB to TTL 모듈 |
|---------------------------|------------------|
| **VCC** | **5V** (중요! 3.3V를 사용하지 마십시오) |
| **GND** | **GND** |
| **TX** | **RX** (교차 연결) |
| **RX** | **TX** (교차 연결) |

⚠️ **참고: TX와 RX는 반드시 교차 연결해야 합니다!**

## 📖 사용 단계

### 1단계: 하드웨어 연결
1. 위의 배선 표에 따라 센서와 USB to TTL을 연결합니다

   VCC -> VCC

   GND -> GND

   RX -> TX

   TX -> RX

2. USB to TTL을 컴퓨터의 USB 포트에 꽂습니다

### 2단계: 프로그램 열기
`HeartRateOximeter.exe`를 실행합니다

### 3단계: 시리얼 포트 설정
1. 올바른 시리얼 포트를 선택합니다(예: COM3)
2. 보드레이트 **9600**(기본)을 선택합니다
3. [연결] 버튼을 클릭합니다

### 4단계: 수집 시작
1. 연결에 성공하면 [수집 시작]을 클릭합니다
2. ✅ 센서 LED가 켜집니다

### 5단계: 모니터링 시작
1. 손가락을 센서 위에 올립니다
2. [모니터링 시작]을 클릭합니다
3. 실시간 데이터를 확인합니다

## ❓ FAQ

### Q1: 시리얼 포트를 찾을 수 없나요?
**A:**
1. USB to TTL 드라이버가 올바르게 설치되었는지 확인합니다
2. USB 케이블을 다시 꽂습니다
3. [새로 고침] 버튼을 클릭하여 다시 스캔합니다

### Q2: 연결에 실패하나요?
**A:**
1. 올바른 시리얼 포트를 선택했는지 확인합니다
2. 시리얼 포트가 다른 프로그램(예: 시리얼 어시스턴트, Arduino IDE)에 점유되어 있지 않은지 확인합니다
3. USB to TTL 모듈이 정상적으로 동작하는지 확인합니다

### Q3: 수집 시작을 클릭한 후 LED가 켜지지 않나요?
**A:**
1. VCC가 5V(3.3V가 아님)에 연결되었는지 확인합니다
2. TX/RX가 교차 연결되었는지 확인합니다
3. 센서 모듈 자체가 손상되지 않았는지 확인합니다

### Q4: 데이터가 항상 -1로 표시되나요?
**A:**
1. [수집 시작]을 클릭했는지 확인합니다
2. 손가락을 센서 위에 올바르게 놓고 LED 영역을 완전히 덮습니다
3. 손가락을 안정적으로 유지하고 몇 초 기다립니다
4. 연결이 느슨하지 않은지 확인합니다

### Q5: 프로그램이 응답하지 않나요?
**A:**
1. 먼저 [모니터링 중지]를 클릭합니다
2. 그런 다음 [수집 중지]를 클릭합니다
3. 마지막으로 [연결 해제]를 클릭합니다
4. 프로그램을 재시작합니다

## ⚠️ 주의사항

1. **배선 순서**: 센서를 먼저 연결한 다음 USB를 꽂습니다
2. **연결 해제 순서**: 모니터링 중지, 그런 다음 수집 중지, 마지막으로 연결 해제
3. **전원 요구 사항**: 센서는 반드시 5V 전원에 연결해야 하며 3.3V에서는 정상적으로 동작하지 않을 수 있습니다
4. **손가락 위치**: 손가락이 광학 영역을 완전히 덮어야 하며 세게 누르지 않습니다
5. **환경 요구 사항**: 센서에 강한 직사광이 비치지 않도록 합니다

문제가 발생하면 다음을 확인하십시오:
1. 하드웨어 배선이 올바른지(특히 TX/RX 교차)
2. 전원이 5V인지
3. USB to TTL 드라이버가 정상적으로 동작하는지
