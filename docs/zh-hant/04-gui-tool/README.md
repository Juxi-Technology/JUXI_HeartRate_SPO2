# 心率血氧監測模組上位機使用說明

## 📋 功能介紹

這是一個圖形化的心率血氧監測上位機程式，支援以下功能：

1. ✅ **序列埠選擇** - 自動掃描可用序列埠
2. ✅ **鮑率選擇** - 支援9600/19200/38400/57600/115200
3. ✅ **連接/斷開** - 一鍵連接/斷開模組
4. ✅ **啟動/關閉採集** - 控制感測器LED亮滅
5. ✅ **開始/停止監測** - 即時顯示資料
6. ✅ **即時資料顯示** - 血氧、心率、溫度
7. ✅ **中英文切換** - 介面可在中英文間切換，預設顯示英文

---

## 🔌 硬體連接

| 心率血氧模組 | USB轉TTL模組 |
|-------------|-------------|
| **VCC** | **5V** (重要！不要接3.3V) |
| **GND** | **GND** |
| **TX** | **RX** (交叉連接) |
| **RX** | **TX** (交叉連接) |

⚠️ **注意：TX和RX必須交叉連接！**

---

## 🚀 執行程式

### 方法一：直接執行Python腳本

1. 安裝相依函式庫：
```bash
pip install pyserial
```

2. 執行程式：
```bash
cd 上位机源代码
python HeartRateOximeter.py
```

---

## 📖 使用步驟

### 第一步：連接硬體
1. 依照上面的接線表連接感測器和USB轉TTL

   VCC->VCC

   GND->GND

   RX->TX

   TX->RX

2. 將USB轉TTL插入電腦USB埠

### 第二步：開啟程式
執行 `HeartRateOximeter.exe`

### 第三步：序列埠設定
1. 選擇正確的序列埠號（如 COM3）
2. 鮑率選擇 **9600**（預設）
3. 點擊【連接】按鈕

### 第四步：啟動採集
1. 連接成功後，點擊【啟動採集】
2. ✅ 感測器LED燈會亮起

### 第五步：開始監測
1. 將手指放在感測器上
2. 點擊【開始監測】
3. 查看即時資料

## ❓ 常見問題

### Q1: 找不到序列埠怎麼辦？
**A:**
1. 檢查USB轉TTL驅動程式是否安裝正確
2. 重新插拔USB線
3. 點擊【重新整理】按鈕重新掃描

### Q2: 連接失敗怎麼辦？
**A:**
1. 確認序列埠選擇正確
2. 確認序列埠沒有被其他程式佔用（如序列埠助手、Arduino IDE）
3. 檢查USB轉TTL是否正常運作

### Q3: 點擊啟動採集後LED不亮？
**A:**
1. 檢查VCC是否接的是5V（不是3.3V）
2. 檢查TX/RX是否交叉連接
3. 確認感測器模組本身沒有損壞

### Q4: 資料一直顯示 -1？
**A:**
1. 確認已經點擊【啟動採集】
2. 將手指正確放在感測器上，完全覆蓋LED區域
3. 保持手指穩定，等待幾秒鐘
4. 檢查接線是否鬆動

### Q5: 程式無回應？
**A:**
1. 先點擊【停止監測】
2. 再點擊【關閉採集】
3. 最後點擊【斷開】
4. 重新啟動程式

---

## ⚠️ 注意事項

1. **接線順序**：先接感測器，再插USB
2. **斷開順序**：先停止監測，再關閉採集，最後斷開連接
3. **電源要求**：感測器必須接5V電源，3.3V可能無法正常運作
4. **手指放置**：測量時手指要完全覆蓋光學區域，不要用力按壓
5. **環境要求**：避免強光直射感測器

---

## 📞 技術支援

如有問題，請檢查：
1. 硬體接線是否正確（特別是TX/RX交叉）
2. 電源是否為5V
3. USB轉TTL驅動程式是否正常
4. 序列埠是否被其他程式佔用
