# 心拍血中酸素モジュール - GUI ユーザーガイド

## 📋 機能

これはグラフィカルな心拍・血中酸素モニタリングプログラムで、次の機能を備えています：

1. ✅ **シリアルポートの選択** - 使用可能なシリアルポートを自動スキャンします
2. ✅ **ボーレートの選択** - 9600/19200/38400/57600/115200 に対応
3. ✅ **接続／切断** - ワンクリックでモジュールを接続／切断します
4. ✅ **収集の開始／停止** - センサー LED の点灯／消灯を制御します
5. ✅ **モニタリングの開始／停止** - リアルタイムでデータを表示します
6. ✅ **リアルタイムデータ表示** - 血中酸素、心拍数、温度
7. ✅ **英語／中国語の切り替え** - いつでもインターフェースの言語を切り替えられます。デフォルトは英語です

---

## 🔌 ハードウェア接続

| 心拍血中酸素モジュール | USB-TTL モジュール |
|---------------------------|------------------|
| **VCC** | **5V**（重要！3.3V は使用しないでください） |
| **GND** | **GND** |
| **TX** | **RX**（クロス接続） |
| **RX** | **TX**（クロス接続） |

⚠️ **注意：TX と RX は必ずクロス接続してください！**

## 🚀 プログラムの実行

### 方法 1：Python スクリプトを直接実行

1. 依存関係をインストールします：
```bash
pip install pyserial
```

2. プログラムを実行します：
```bash
cd 上位机源代码
python HeartRateOximeter.py
```

---

## 📖 使用手順

### ステップ 1：ハードウェアを接続
1. 上記の配線表に従って、センサーと USB-TTL を接続します

   VCC -> VCC

   GND -> GND

   RX -> TX

   TX -> RX

2. USB-TTL をパソコンの USB ポートに接続します

### ステップ 2：プログラムを開く
`HeartRateOximeter.exe` を実行します

### ステップ 3：シリアルポートの設定
1. 正しいシリアルポートを選択します（例：COM3）
2. ボーレートを **9600** に設定します（デフォルト）
3. [接続] ボタンをクリックします

### ステップ 4：収集を開始
1. 接続に成功したら [収集を開始] をクリックします
2. ✅ センサー LED が点灯します

### ステップ 5：モニタリングを開始
1. 指をセンサーに置きます
2. [モニタリングを開始] をクリックします
3. リアルタイムのデータを表示します

## ❓ FAQ

### Q1: シリアルポートが見つかりませんか？
**A:**
1. USB-TTL ドライバーが正しくインストールされているか確認してください
2. USB ケーブルを再接続してください
3. [更新] ボタンをクリックして再スキャンしてください

### Q2: 接続に失敗しましたか？
**A:**
1. 正しいシリアルポートが選択されていることを確認してください
2. シリアルポートが他のプログラム（シリアルアシスタント、Arduino IDE など）に占有されていないことを確認してください
3. USB-TTL モジュールが正常に動作しているか確認してください

### Q3: [収集を開始] をクリックしても LED が点灯しませんか？
**A:**
1. VCC が 5V に接続されているか確認してください（3.3V ではなく）
2. TX/RX がクロス接続されているか確認してください
3. センサーモジュール自体が損傷していないことを確認してください

### Q4: データが常に -1 と表示されますか？
**A:**
1. [収集を開始] をクリックしたことを確認してください
2. 指をセンサーに正しく置き、LED 領域を完全に覆ってください
3. 指を安定させ、数秒待ちます
4. 接続の緩みがないか確認してください

### Q5: プログラムが応答しませんか？
**A:**
1. まず [モニタリングを停止] をクリックします
2. 次に [収集を停止] をクリックします
3. 最後に [切断] をクリックします
4. プログラムを再起動します

---

## ⚠️ 注意事項

1. **配線の順序**：先にセンサーを接続し、その後で USB を差し込みます
2. **切断の順序**：モニタリングを停止し、次に収集を停止し、最後に切断します
3. **電源要件**：センサーは 5V 電源に接続する必要があります。3.3V では正常に動作しない可能性があります
4. **指の置き方**：指は光学領域を完全に覆うようにし、強く押さないでください
5. **環境要件**：センサーへの強い直射光を避けてください

## 📞 テクニカルサポート

問題が発生した場合は、次を確認してください：
1. ハードウェア配線が正しいか（特に TX/RX のクロス接続）
2. 電源が 5V であるか
3. USB-TTL ドライバーが正常に動作しているか
4. シリアルポートが他のプログラムに占有されていないか
