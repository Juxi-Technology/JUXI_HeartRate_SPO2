# 心率血氧监测模块上位机使用说明

## 📋 功能介绍

这是一个图形化的心率血氧监测上位机程序，支持以下功能：

1. ✅ **串口选择** - 自动扫描可用串口
2. ✅ **波特率选择** - 支持9600/19200/38400/57600/115200
3. ✅ **连接/断开** - 一键连接/断开模块
4. ✅ **启动/关闭采集** - 控制传感器LED亮灭
5. ✅ **开始/停止监测** - 实时显示数据
6. ✅ **实时数据显示** - 血氧、心率、温度
7. ✅ **中英文切换** - 界面可在中英文间切换，默认显示英文

---

## 🔌 硬件连接

| 心率血氧模块 | USB转TTL模块 |
|-------------|-------------|
| **VCC** | **5V** (重要！不要接3.3V) |
| **GND** | **GND** |
| **TX** | **RX** (交叉连接) |
| **RX** | **TX** (交叉连接) |

⚠️ **注意：TX和RX必须交叉连接！**

---

## 🚀 运行程序

### 方法一：直接运行Python脚本

1. 安装依赖库：
```bash
pip install pyserial
```

2. 运行程序：
```bash
cd 上位机源代码
python HeartRateOximeter.py
```

---

## 📖 使用步骤

### 第一步：连接硬件
1. 按照上面的接线表连接传感器和USB转TTL

   VCC->VCC

   GND->GND

   RX->TX

   TX->RX

2. 将USB转TTL插入电脑USB口

### 第二步：打开程序
运行 `HeartRateOximeter.exe`

### 第三步：串口设置
1. 选择正确的串口号（如 COM3）
2. 波特率选择 **9600**（默认）
3. 点击【连接】按钮

### 第四步：启动采集
1. 连接成功后，点击【启动采集】
2. ✅ 传感器LED灯会亮起

### 第五步：开始监测
1. 将手指放在传感器上
2. 点击【开始监测】
3. 查看实时数据

## ❓ 常见问题

### Q1: 找不到串口怎么办？
**A:**
1. 检查USB转TTL驱动是否安装正确
2. 重新插拔USB线
3. 点击【刷新】按钮重新扫描

### Q2: 连接失败怎么办？
**A:**
1. 确认串口选择正确
2. 确认串口没有被其他程序占用（如串口助手、Arduino IDE）
3. 检查USB转TTL是否正常工作

### Q3: 点击启动采集后LED不亮？
**A:**
1. 检查VCC是否接的是5V（不是3.3V）
2. 检查TX/RX是否交叉连接
3. 确认传感器模块本身没有损坏

### Q4: 数据一直显示 -1？
**A:**
1. 确认已经点击【启动采集】
2. 将手指正确放在传感器上，完全覆盖LED区域
3. 保持手指稳定，等待几秒钟
4. 检查接线是否松动

### Q5: 程序无响应？
**A:**
1. 先点击【停止监测】
2. 再点击【关闭采集】
3. 最后点击【断开】
4. 重启程序

---

## ⚠️ 注意事项

1. **接线顺序**：先接传感器，再插USB
2. **断开顺序**：先停止监测，再关闭采集，最后断开连接
3. **电源要求**：传感器必须接5V电源，3.3V可能无法正常工作
4. **手指放置**：测量时手指要完全覆盖光学区域，不要用力按压
5. **环境要求**：避免强光直射传感器

---

## 📞 技术支持

如有问题，请检查：
1. 硬件接线是否正确（特别是TX/RX交叉）
2. 电源是否为5V
3. USB转TTL驱动是否正常
4. 串口是否被其他程序占用
