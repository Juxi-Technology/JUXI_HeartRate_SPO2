# 心率血氧上位机 —— 运行教程

本文只讲**怎么把 `HeartRateOximeter.py` 跑起来**。界面功能与参数说明见 [`docs/zh-hans/04-gui-tool/README.md`](../../docs/zh-hans/04-gui-tool/README.md)。

---

## 1. 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 7 / 10 / 11（Tk 界面，macOS / Linux 理论上也能跑） |
| Python | 3.8 及以上，安装时勾选 **Add Python to PATH** |
| 依赖库 | `pyserial`（唯一的第三方库）；`tkinter` 是 Python 自带 |

验证 Python 是否可用：

```bash
python --version
```

若提示找不到命令，改用 `py --version`，下文命令里的 `python` 同样换成 `py`。

---

## 2. 安装依赖并运行

### 方式 A：直接运行已打包的 exe（不需要 Python）

双击 `HeartRateOximeter/dist/HeartRateOximeter.exe` 即可。这是单文件程序，可以单独拷到任何 Windows 电脑上运行。

### 方式 B：从源码运行

1. 安装依赖：

```bash
pip install pyserial
```

如果下载慢，换国内镜像：

```bash
pip install pyserial -i https://pypi.tuna.tsinghua.edu.cn/simple
```

2. 进入源码目录并启动：

```bash
cd "HeartRateOximeter/上位机源代码"
python HeartRateOximeter.py
```

命令行没有任何报错、弹出窗口即为成功。注意：**源码运行时会占用这个命令行窗口**，关掉窗口程序就退出。

> 没有窗口弹出？检查是不是 Python 自带的是精简版（不含 tkinter），或临时改用方式 A。

## 3. 硬件接线

模块通过 **UART** 与电脑通信，需要一只 USB 转 TTL 模块（CH340 / CP2102 / FT232 等）。

| 传感器 | USB 转 TTL |
|--------|-----------|
| VCC | 5V |
| GND | GND |
| TX | RX |
| RX | TX |

⚠️ **TX / RX 必须交叉连接**；VCC 请接 5V，不要接 3.3V。
插上 USB 转 TTL 后，Windows 设备管理器「端口 (COM 和 LPT)」里应出现 `USB-SERIAL CH340 (COMx)` 之类的条目。

---

## 4. 界面操作步骤

1. 打开程序，界面默认是英文，右上角下拉框可切换 **中文**。
2. **串口设置**：
   - `串口` 下拉框选择刚出现的 COM 口（没看到就点「刷新」）；
   - `波特率` 保持默认 **9600**；
   - 点「连接」。成功会弹提示，状态变为“已连接，待采集”。
3. 点「启动采集」。此时模块上的 **LED 点亮**，状态变为“采集已启动，LED已亮”。
4. 点「开始监测」，「实时数据」区每 2 秒刷新一次血氧、心率、温度。
5. 把手指放在传感器上，数据稳定需要几秒钟；静止、贴合、别透光效果最好。
6. 使用结束：先「停止监测」→「关闭采集」（LED 熄灭）→「断开」，再关窗口。

> 顺序不能颠倒：**必须先「连接」**，否则「启动采集」按钮是灰的；**必须先「启动采集」**，否则读不到有效数据。

数据显示 `-1` 表示模块返回的原始值为 0，通常是手指没放好或还没采集到。

## 5. 已知行为 / 常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 串口列表为空 | USB 转 TTL 驱动没装（CH340 需装驱动），或线没插好；点「刷新」重试 |
| 连接失败 `PermissionError` / `拒绝访问` | 该串口被别的程序占用（串口调试助手、Arduino IDE 串口监视器等），关掉后再连 |
| 连接失败 `could not open port` | COM 口号选错，或设备已拔出 |
| 监测一直显示 `-` 或 `-1` | 没点「启动采集」，或模块没供电、TX/RX 没交叉 |
| 停止监测后数据还在变 | 停止监测后界面保留最后一次读数，属正常 |
| 程序卡死 | 拔插 USB 会让串口句柄失效；断开→重新连接即可，必要时重启程序 |
| exe 双击没反应 | 杀毒软件误报拦截；exe 是无控制台窗口的，报错不会显示，先改用源码运行定位问题 |

## 6. 通信协议速查（便于二次开发）

模块地址 `0x20`，Modbus RTU，CRC16（低字节在前）。

| 操作 | 发送帧 | 说明 |
|------|--------|------|
| 启动采集 | `20 10 00 10 00 01 02 00 01` + CRC | 写寄存器 `0x0010` = 1，LED 亮 |
| 关闭采集 | `20 10 00 10 00 01 02 00 02` + CRC | 写寄存器 `0x0010` = 2，LED 灭 |
| 读心率血氧 | `20 03 00 06 00 04` + CRC | 读 `0x0006` 起 4 个寄存器 |
| 读温度 | `20 03 00 0A 00 01` + CRC | 读 `0x000A`，`整数 + 小数/100` |

读心率血氧的响应帧 13 字节：`20 03 08` + 数据，其中 `resp[3]` 为血氧（%），`resp[5..8]` 为 32 位大端心率（BPM）。
